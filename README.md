## About

I started out building interfaces and got curious about what happens after the request leaves the browser. That curiosity is currently taking the shape of Spring Boot, auth flows, and more REST APIs than I'd like to admit.

The long-term plan is less about the stack and more about who it's for — I want to build software for people who usually get skipped over by it: small businesses, local farmers, communities outside the usual tech radius. Good tools shouldn't be a city privilege.
